# Roadmap

This roadmap describes possible future work. Items are plans, not implemented features.

## v0.1.0 - First working version

- [x] Single-URL HTML fetch
- [x] Title and meta description checks
- [x] Canonical and robots meta extraction
- [x] Heading and image alt inspection
- [x] Internal/external link counts
- [x] Terminal and JSON reports
- [x] Unit tests and GitHub Actions

## Potential next steps

- [ ] Save JSON reports to a file
- [ ] Check Open Graph and Twitter card metadata
- [ ] Detect structured-data script blocks
- [ ] Add sitemap discovery with explicit crawl limits and delays
- [ ] Add conservative internal-link status checks
- [ ] Add WordPress and WooCommerce examples
- [ ] Package the CLI for installation with pip

Priorities will depend on issues, feedback, and maintainer capacity.
