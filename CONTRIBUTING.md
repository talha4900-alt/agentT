# Contributing

Thanks for considering a contribution.

- Check existing issues before starting work.
- For larger changes, open an issue to discuss the approach.
- Keep changes focused and explain the problem they solve.
- Never commit credentials, API keys, customer data, or private website content.

## Development

Python 3.10 or newer is required. The project currently uses only the standard library.

Run tests:

```bash
python -m unittest discover -s tests -v
```

Try the CLI:

```bash
python -m agentt_seo https://example.com
```

## Pull requests

Please include a clear description, tests for new behavior or bug fixes, documentation updates where needed, and known limitations. Be respectful and constructive in discussions.
